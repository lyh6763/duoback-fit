## S03 Fit 질문 — `Mobile/S03_FitStep` (Mobile 우선)

하나의 템플릿에 질문 유형 3가지(선택 카드, 슬라이더, 복수 선택)를 갈아 끼운다.

```
┌──────────────────────────┐
│ FitHeader (56)            │
│  ← 이전   "2 / 6"   × 닫기 │
│  ProgressBar (4, 6칸 분할)  │
├──────────────────────────┤
│ Question (약 140)          │
│  Caption "몸 정보"          │
│  H2 "키와 체중을            │
│      알려주세요"            │
│  Body/S 보조 설명           │
├──────────────────────────┤
│ Answer 영역 (auto)          │
│  [유형 A: 단일 선택]         │
│   OptionCard × 2~4 (세로)   │
│   선택 즉시 다음 단계        │
│                            │
│  [유형 B: 슬라이더] step 2    │
│   BodySilhouette (240)     │
│    키 값에 따라 크기 변화,    │
│    권장 좌판 높이 가이드선     │
│   RangeSlider "키" 172cm    │
│   RangeSlider "체중" 68kg   │
│                            │
│  [유형 C: 복수 선택] step 5   │
│   OptionChip 그리드 (2열)    │
├──────────────────────────┤
│ StickyFooter (88)          │
│  Button/Primary/L full     │
│  "다음" (B, C 유형만)        │
└──────────────────────────┘
```

- **Desktop `Desktop/S03_FitStep`:** 중앙 640 폭 단일 컬럼 카드. 좌측에 단계 목록(완료 ✓, 현재 강조)을 세로로 보여주는 사이드 레일 240을 둔다. 실루엣은 슬라이더 오른쪽에 배치.
- **전환:** 단계 간 가로 슬라이드 200ms(`prefers-reduced-motion`이면 페이드만).

## S04 Fit 결과 — `Mobile/S04_FitResult` / `Desktop/S04_FitResult`

```
Desktop
┌───────────────────────────────────────────────┐
│ GNB                                            │
├───────────────────────────────────────────────┤
│ Section/ProfileSummary (약 200, Sand 배경)        │
│  [좌 8] Caption "당신의 권장 좌판 높이"            │
│         Display "455mm"  + 입력 요약 칩들          │
│         (키 172 · 6~9시간 · 허리) "수정"           │
│  [우 4] 링크 "계산 방식 보기" / "다시 하기"        │
├───────────────────────────────────────────────┤
│ (조건부) Notice "발받침 사용을 권장해요"            │
├───────────────────────────────────────────────┤
│ Section/TopMatch (약 640)                       │
│  [좌 6] 의자 이미지 (색상 스와치)      ← 브랜드 레이어 │
│  [우 6] H2 모델명 + 가격                          │
│         한 줄 요약 "허리를 잘 받쳐주는 모델이에요"     │
│         ┌ DataCard ──────────────────┐ ← 데이터 레이어 │
│         │ ScoreBadge/L "적합도 92"     │            │
│         │ FitGauge/L (눈금 + 내 위치)   │            │
│         │ ReasonList × 3              │            │
│         │  ✓ 좌판 높이 ··· 455 mm      │            │
│         │  ✓ 요추 지지 ··· 조절형       │            │
│         └────────────────────────────┘            │
│         CautionNote (있을 때)                     │
│         Button/Primary "자세히 보기"               │
│         Button/Secondary "매장에서 앉아보기"         │
├───────────────────────────────────────────────┤
│ Section/ScoreBreakdown (약 280)                  │
│  DataCard: 점수 구성 막대 4행                       │
│   체형 적합 ████████░ 36 / 40                     │
│   사용 패턴 ███████░░ 22 / 25 …                   │
│   합계 "적합도 92" · 링크 "계산 방식 보기"            │
├───────────────────────────────────────────────┤
│ Section/Alternatives (약 440)                    │
│  H3 "이런 선택지도 있어요"                         │
│  ChairCard/Result × 2 (6-6)                     │
├───────────────────────────────────────────────┤
│ Section/Actions (약 160)                         │
│  Button "상위 3개 비교하기" · "결과 공유"            │
└───────────────────────────────────────────────┘
```

- **Mobile:** ProfileSummary → TopMatch(이미지 위, 정보 아래) → ScoreBreakdown(접힘: "점수 구성 보기") → Alternatives(세로 스택) → 하단 고정 바 "비교하기 / 공유".
- **레이어 구분:** 이미지, 모델명, 요약 문장, 버튼은 브랜드 레이어(paper 배경)에, 점수와 게이지, 근거는 흰 DataCard 안에 둔다. 규칙은 [04-ui-spec.md](04-ui-spec.md) 0장 참고.
- **FitGauge:** 눈금이 있는 가로 바에 의자의 좌판 조절 범위와 내 권장 높이(마커)를 함께 표시한다. 이 프로젝트를 상징하는 시각 요소다.
- **화면 하단 고정 문구:** "실제 착좌감은 매장에서 확인해 주세요"
- **빈 상태 `S04_FitResult--Empty`:** 일러스트 + "맞는 모델이 없어요" + 입력 수정 / 매장 상담.
