## 사용자 여정 요약

1. **찾기 (P1 직장인):** 홈 → Fit Finder 6단계 → 결과에서 1순위 확인 → 상세에서 몸 기준 스펙 확인 → 전시 매장 확인
2. **비교 (P1 직장인):** 목록에서 "내 키에 맞는 의자만" 필터 → 2~3개 비교 담기 → 비교표에서 차이 확인 → 링크 공유
3. **자녀용 (P2 부모):** Fit Finder에서 "자녀(학생)" 선택 → 아이 키 입력 → "성장해도 오래 사용" 근거와 함께 학생용 모델 추천 → 매장 방문

## 플로우 다이어그램

### 핵심 흐름 — Fit Finder

```
S01 [홈]
 ├─ 히어로 CTA "1분 만에 내 의자 찾기" → S02 [Fit 시작]
 │    ├─ 저장된 진행 상태 있음 → O04
 │    │    ├─ 이어서 하기 → S03 (저장된 step)
 │    │    └─ 처음부터 → S03 (step=1)
 │    └─ 시작하기 → S03 (step=1)
 │
 └─ 시나리오 카드 "재택 8시간 / 아이 첫 의자 / 허리가 불편해요"
      → S03 (해당 답변을 미리 채운 상태로 다음 미답변 단계부터)

S03 [Fit 질문]  step 1 → 2 → 3 → 4 → 5 → 6
 ├─ 이전 / 브라우저 뒤로 → 이전 step (step=1에서 뒤로 → S02)
 ├─ 답변 선택 → 자동으로 다음 step (단일 선택만. 슬라이더·복수 선택은 "다음" 버튼)
 └─ step 6 완료 → 계산 → S04 [결과]   (프로필을 localStorage에 저장)

S04 [Fit 결과]
 ├─ 1순위 / 대안 카드 클릭 → S06 [상세] (매칭 이유 표시)
 ├─ "상위 3개 비교하기" → 비교 대상 교체 확인 → S07 [비교]
 ├─ "매장에서 앉아보기" → S08 ?model=1순위
 ├─ 입력 요약 "수정" → S03 (해당 step, 나머지 답변 유지)
 ├─ "다시 하기" → S03 step=1 (기존 답변 초기화)
 ├─ "계산 방식 보기" → S09
 └─ "결과 공유" → 링크 복사 → O02 토스트
```

### 탐색·비교 흐름

```
S05 [의자 목록]
 ├─ 필터·정렬 변경 → S05 (URL 쿼리 갱신, 결과 0개면 빈 상태)
 ├─ 카드 색상 스와치 → 카드 이미지만 변경 (이동 없음)
 ├─ 카드 "비교 담기" → O01 트레이 등장 / 갱신 + O02
 │    └─ 이미 3개 → O02 "최대 3개" + 트레이 흔들림 강조
 └─ 카드 클릭 → S06

O01 [비교 트레이]
 ├─ 썸네일 × → 해당 모델 빼기
 ├─ "비교하기" (2개 이상 활성) → S07
 └─ "비우기" → 트레이 숨김

S06 [의자 상세]
 ├─ 프로필 없음 → "내 몸에 맞는지 확인하기" → S02
 ├─ "비교 담기" → O01
 ├─ "이 모델 전시 매장" → S08 ?model=slug
 └─ 관련 모델 → S06 (다른 slug, 스크롤 맨 위)

S07 [비교]
 ├─ "차이 나는 항목만" 토글 → 표 갱신
 ├─ 열 헤더 × → 모델 빼기 (URL·트레이 동기화)
 ├─ 빈 슬롯 "모델 추가" → S05 (돌아오면 S07 유지)
 └─ 모델명 → S06
```

## 엣지 케이스 / 예외 흐름

| 상황 | 처리 |
|---|---|
| 하중 조건으로 모든 모델 제외 | S04 "맞는 모델이 없어요" 상태 → 매장 상담 CTA, 입력 수정 |
| 권장 좌판 높이가 모든 모델보다 낮음 | 결과는 표시하고 상단에 "발받침 사용을 권장해요" 안내 고정 |
| `?step=4`로 바로 접근했는데 1~3 답변이 없음 | 첫 미답변 step으로 리다이렉트 |
| 잘못된 공유 코드 `?p=` | S04 대신 "링크가 올바르지 않아요" + Fit 시작 CTA |
| 공유 링크로 타인 결과 열람 | 결과 표시 + "내 결과로 저장할까요?" 배너 (자동 저장하지 않음) |
| `/compare?m=` 에 없는 slug 포함 | 유효한 모델만 표시. 0개면 빈 상태 + S05 CTA |
| `/chairs/없는-slug` | `notFound()` → S11 |
| 비교 트레이가 콘텐츠를 가림 | 트레이 높이만큼 페이지 하단 패딩 추가, 푸터 위에서 정지 |
| localStorage 사용 불가(시크릿 모드 등) | 기능은 동작하고 저장만 생략 (try/catch) |
| 슬라이더를 키보드로 조작 | 방향키 1cm, PageUp/Down 5cm, 값 읽어주기(`aria-valuetext="172센티미터"`) |
